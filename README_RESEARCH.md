# PPT-PTTA-ACCV2026

This repository contains research code for lightweight test-time adaptation on top of PPT:
Progressive Pretext Task Learning for Human Trajectory Prediction.

Base code:
- Official PPT repository: https://github.com/iSEE-Laboratory/PPT
- Paper: Progressive Pretext Task Learning for Human Trajectory Prediction, ECCV 2024

Research direction:
- Backbone: PPT
- Goal: Robust human trajectory prediction under test-time shifts
- Planned method: Frozen PPT + lightweight adapter + pretext-consistent test-time adaptation

Important:
- Datasets are not included.
- Pretrained models and trained checkpoints are not included.
- Experiment results are not included.
- Use the official PPT instructions to prepare data and pretrained models.
